# 能力训练平台 · Training

> 钟锐的能力训练平台 — 主线是 **策略分析**（经营分析 / 商业化运营 / 渠道质量 / 增量评估），
> 依据公开招聘要求反推能力模型，逐项设计可训练模块。AI 在这里是**提效工具**，不是求职身份。
> 纯前端实现（sql.js 在浏览器内跑真实 SQLite），**零服务器、零成本**，可部署 GitHub Pages。

线上地址：**https://zr-president.github.io/training/**（已上线）

> **部署方式**：GitHub Pages 从 `gh-pages` 分支发布。因此改完代码后除了提交到 `main`，
> 还要同步一次 gh-pages —— 直接运行 `python tools/deploy.py` 即可（它会检查工作区是否干净并自动同步）。
>
> 想改成从 `main` 直接发布也可以：仓库 Settings → Pages → Source 选 `main` / `/ (root)`，
> 之后就不需要这个脚本了。

## 本地打开方式（不需要服务器）

**直接双击 index.html 即可**，不需要启动任何本地服务 —— 页面全部通过 <script> 标签加载，
不依赖 fetch，所以 ile:// 协议下功能完全正常（SQL 执行、数据集加载、进度保存全部可用）。
实测：ile:// 下端到端自检 61/61 通过。

> 如果想用本地服务器预览（可选）：python -m http.server 8924。但没必要。

## 怎么用（3 步）

1. **打开首页就是「远征指挥台」** → 选今天有多少时间（15/30/60 分钟），它直接给你一组任务，并显示每项推荐原因
2. **按天练** → 30 天训练计划（91 个任务）或直接做指挥台推荐的任务，做完打勾；不用纠结先学什么
3. **验证产出** → 用判读题、AI 工作流设计题、语音复述检验 —— **能讲清楚才算真会**

## 答案在哪看

每道题都有参考答案，位置如下：

| 模块 | 答案位置 |
|------|---------|
| SQL 训练场 / 数据集实验室 / Case 拆解 / PRD 工坊 / Python 案例 | 题目下方的**绿色「参考答案 ·」折叠区**，点开即参考解与讲解 |
| 判读题（指标设计 / 实验分析 / AI Agent / AI PM） | 点「提交判分」逐项显示对错原因；或点「👀 直接看答案（不判分）」直接看 |
| Python 数据分析案例 | 直接展示代码 + **真实运行结果**（真跑出来写入的，非手写示意） |
| 面试题库 | 每题直接给出「考察意图 / 回答框架 / 参考要点 / 加分与减分说法」 |

> 判读题若使用「直接看答案」，本题会标注为**不计入一次做对率**，保证这个指标能反映真实水平。

## 求职主线：策略分析

| 层级 | 方向 | 需要的能力 | 核心门槛 |
|------|------|-----------|---------|
| **主投 A** | 经营分析 / 业务分析 / 运营分析 | 经营报表、指标树、成本管控、预算预测、建议落地与归因 | 能把「数字变化」翻译成「业务结论 + 下一步动作」 |
| **主投 B** | 商业化运营 / 渠道运营 / 增长运营 | 单位经济、渠道质量、预算协调、增量评估、归因边界 | 能判断「这个增长是不是我们创造的」 |
| 邻近 | 商家运营 / 渠道策略 / 销售运营 / 数据运营 | SQL、宽表、报表、商家生命周期、CRM | SQL 现场能写、数据质量能兜住 |

> **AI 的位置**：`AI 产品经理` 模块保留为**能力扩展**（判断什么该用 AI、怎么验收、成本怎么算），
> 但不作为求职主线 —— 转 AI 产品需要「需求发现 → 优先级 → 产品交付 → 用户验证」的完整经历，
> 而现有履历的强项在「懂业务经营 + 能分析数据 + 能推动执行」。

### Python 数据分析案例（教学模块）

**定位是教学，不要求在线运行**——把代码复制到本地 Jupyter / VS Code 跑即可。

| 分组 | 案例 |
|------|------|
| 数据读取与体检 | 读取 + 体检三件套 / 缺失值与重复值 / **Excel 多 sheet 读写** |
| 数据清洗与加工 | 日期解析与类型转换 / 条件筛选与向量化新增列 / 分箱与用户分层（cut vs qcut）/ **长宽表转换 melt 与 pivot** / **分层抽样** |
| 聚合与合并 | groupby 多指标 agg / 多表 merge 行数校验 / 透视表 pivot_table / 组内占比 transform / **表格拼接 concat** |
| 时间序列与留存 | **时间重采样与移动平均** / 按月聚合与环比 / **次日留存率 cohort 标准写法** / 漏斗转化率 |
| 排名与统计 | 分组 TopN 与 rank / 相关性分析 / 卡方检验 / 结果导出 / **给图表准备数据** |

每个案例包含：**场景 → 代码（语法高亮 + 一键复制）→ 真实运行结果 → 逐点讲解 → 常见坑**。

**面试常考标签**：每个案例都标注了重要程度（`🔥 面试必考` / `面试常考` / `A/B 必考` / `最容易错` / `基本功`），侧边列表里 🔥 开头的是必须掌握的。

> ⚠️ **运行结果是用真实 pandas 2.2 跑出来并自动写入数据的**（生成器 `tools/gen_pycases.py` 会逐条执行代码并捕获 stdout），所以页面上的输出与代码严格一致，不是手写示意。

另有 **6 道代码实例题**（纯 Python 留存 / pandas 留存 / DAU / 卡方检验 / LTV-CAC / 相关性），每题给出任务、起始模板、**参考解**与**真实运行得到的预期结果**，可自己写完再对照。

### AI 产品经理模块（运营转型专项）

针对「从运营转 AI 产品经理」的实际情况设计，分三个 Tab：

1. **能力对照**：8 维能力逐项对照「你的运营积累 / AI PM 要求 / 可直接迁移 or 需重点补 / 怎么讲怎么补」，并给出面试话术建议
2. **判读题（12 题，自动判分）**：AI 适用性判断、RICE 优先级、AI 验收标准、RAG/微调/Prompt 选型、幻觉治理、token 成本测算、PRD 结构、AI 功能指标、转型路径、向上沟通
3. **面试题库（18 题，6 个分类，高频 10 题）**：开场与转型 / 产品与需求 / AI 技术理解 / 数据与实验 / 项目与协作 / 反问环节 —— 每题给出「考察意图 → 回答框架 → 参考要点 → 加分说法 / 减分说法」，可标记"已准备"追踪进度
4. **PRD 工坊（4 套，开放题）**：AI 周报 PRD / AI 客服 PRD（含幻觉兜底）/ 模型选型与成本测算 / 灰度与评测方案 —— 每套都有分模块填写区 + 参考 PRD + 常见错误

> 核心判断：**能用确定性代码解决的事，绝不要用模型**；AI 功能 PRD 的价值集中在「不做什么」和「出问题怎么办」。

### 提效计算器的设计要点

它不是为了算出一个好看的数，而是为了**暴露常见的高估**：多数人只算「人工耗时 − Agent 生成耗时」，忽略了**审核时间**与**维护调试时间**。计算器会同时给出「错误算法」与「真实算法」的结果，并显示高估幅度——这个差距本身就是面试时的专业度体现。

## 训练数据集

场景：内容社区 App「增长实验室」，数据区间 2026-08-01 ~ 2026-09-10

| 表 | 说明 | 行数 |
|----|------|------|

**渠道差异化设计**（便于练习留存、ROI、LTV/CAC）：
- 朋友推荐 —— 留存最高、零成本（自然流量）
- 抖音 —— 量最大但留存最低、成本最高
- 微信 / 小红书 / B站 / 应用商店 —— 介于两者之间

数据集可用 `tools/gen_dataset.py` 重新生成（固定随机种子，结果可复现）。

## 技术说明

- **主题系统**：亮色为默认，支持**夜间模式**切换；提供 6 套主题色（靛蓝/深海蓝/墨绿金/玫瑰金/琥珀暖/石墨灰）
  - 与个人网站**共用** `localStorage` 键 `theme` / `themeColor` → 两站主题选择自动同步
  - 科技感通过渲染实现（渐变光晕 + 网格叠加 + 玻璃顶栏 + 模块配色 + 渐变标题），而非深色背景
  - 13 个模块各有独立配色（SQL 蓝 / 实验室 青 / 指标 紫 / 实验 橙 / Case 玫红 / Agent 绿 / 雷达 琥珀 / Python 青绿 / 数据 灰蓝 / AI PM 玫紫 / AI 工作流 天蓝 / 语音 玫瑰 / 计划 靛蓝）
- **SQL 引擎**：`sql.js` 1.10.2（SQLite 的 WebAssembly 版），浏览器内执行真实 SQL
- **判分方式**：你的结果集与参考解结果集对比
  - 含 `ORDER BY` 的题按顺序比对；否则按**无序多重集**比对（不对写法做限制，思路对就给过）
  - 数字容差 3 位小数；`'3'` 与 `3` 视为相等；列名可不同（只看列数）
- **体积策略**：数据集 472KB **懒加载**——只有进入 SQL 模块才下载；首页只加载 0.9KB 元数据
- **进度存储**：`localStorage`（`tp_progress_v1`），只存在你自己的浏览器
- **自检**：访问 `index.html?selftest=1` 会跑通全部参考解并输出 **61/61**（SQL 31 + LAB 30）
